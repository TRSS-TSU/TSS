Unity Starter Assets

Apply Idle, Walk, and Run Animations

Use Animator Override Controllers to test character animations without changing the movement controller.

Baseline: keep the Starter Assets Third Person Controller in charge of movement. Replace animation clips only.
1

Import the FBX animation files

Place the idle, walk, and run files in Assets/Animations/ReadyPlayerMe/.

Select each FBX in Unity and use the Inspector to prepare it as a humanoid animation.

2

Set the Rig tab to Humanoid

For every animation FBX, open Inspector > Rig.

  • Animation Type: Humanoid
  • Avatar Definition: Create From This Model
  • Click Apply
3

Loop and lock root motion

Open Inspector > Animations for each clip.

  • Enable Loop Time
  • Set Root Transform Rotation to Bake Into Pose
  • Set Root Transform Position Y to Bake Into Pose
  • Set Root Transform Position XZ to Bake Into Pose

This prevents the animation from pulling the model away from the camera/controller.

4

Create an Animator Override Controller

In the Project window, choose Create > Animator Override Controller.

Assign this base controller:

Assets/Starter Assets/Runtime/ThirdPersonController/Character/Animations/StarterAssetsThirdPerson.controller
5

Replace only idle, walk, and run

In the override controller, swap these clips and leave the rest alone.

Starter Assets clip Replacement
Stand--Idle Idle clip
Locomotion--Walk_N Walk clip
Locomotion--Run_N Run clip
Locomotion--Run_S Run clip, optional
6

Assign the override to the player

Select Starter Player in the scene.

  • Animator Controller: your new override controller
  • Apply Root Motion: Off

Press Play and test idle, walk, and run. If the character jumps forward, re-check the root transform settings first.

Quick Validation

  • Unity enters Play Mode with no animation errors.
  • The character animates while the Starter Assets controller moves it.
  • The model stays with the controller and does not slide away from the camera.
  • The camera follows the character normally inside the building.
